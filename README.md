# Crystal Clear Beauty – Manual Testing

## 📌 Project Overview

**Crystal Clear Beauty** is an AI-powered cosmetics e-commerce application. This repository contains the manual testing documentation prepared to evaluate the application's **functionality**, **usability**, and **access control**.

---

## 🎯 Testing Scope

| Area | Features Covered |
|------|------------------|
| **Authentication** | User Registration and Login, Google Login, Password Recovery, Logout |
| **Shopping** | Product Browsing and Search, Shopping Cart and Cart Calculation, Checkout and Order Placement |
| **User Features** | Product Reviews, User Profile, Contact Page |
| **Admin** | Admin Product and Order Management |
| **Security** | Access Control |
| **Quality** | UI and Responsiveness, Input Validation |
